# 같이가개 🐾

**차에서 반려견 동반 가능 장소를 찾고, 휴식 안내와 맞춤 온도로 반려견과의 이동을 처음부터 끝까지 돕는 Pleos Connect 차량용 앱**

2026 현대자동차그룹 차량용 앱 개발 공모전(Pleos Connect) 출품작

---

## 왜 만들었나요?

- 반려견과의 외출은 대부분 자가용에서 시작되지만(반려동물 동반 여행 중 자가용 이용 81.7%), 동반 가능한 장소 정보는 지도 앱·블로그·SNS에 흩어져 있습니다.
- 정작 정보가 가장 필요한 순간, 보호자는 운전대를 잡고 있습니다.
- 같이가개는 **차 안에서 말 한마디로** 반려견과 갈 수 있는 곳을 찾고, 차량 내비게이션 길안내까지 바로 이어 줍니다.

## 주요 기능

| 단계 | 기능 | 설명 |
|---|---|---|
| 탑승 | 탑승 확인 · 반려견 모드 | 앱 실행 시 "콩이와 함께 탑승하나요?"를 묻고, 버튼 또는 음성("응/아니")으로 답하면 반려견 모드가 켜져요. |
| 탑승 | QR 프로필 등록 | 차량 화면의 QR을 휴대폰으로 스캔해 사진·이름·견종·나이·몸무게·특이사항을 입력하면 차량 앱에 자동으로 반영돼요. |
| 이동 | 반려견 맞춤 온도 | 견종·털 유형·나이·체중으로 서버가 맞춤 온도를 계산해 실내 온도와 함께 보여 줘요. 정차(P) 중에만 조절할 수 있어요. |
| 목적지 | 음성 장소 검색 | "근처에 콩이랑 갈 수 있는 카페 찾아줘" → 반려견 동반 가능 장소를 가까운 순으로 3곳 보여 줘요. 결과가 없으면 5km → 10km → 20km로 넓혀요. |
| 목적지 | 동반 조건 칩 · 장소 정보 | 크기 제한, 목줄·입마개 등 동반 조건을 칩으로 보여 주고, 영업 시간·주차·주소·전화를 확인할 수 있어요. |
| 목적지 | 확인 후 길안내 | [안내 시작] → "OO로 안내할까요?" → "응"이라고 답하면 차량 내비게이션 길안내가 시작돼요. |
| 장거리 | 2시간 휴식 권고 | 연속 주행 2시간이 넘으면 화면과 음성으로 휴식을 권하고, "응"이면 반려견과 쉬어 갈 공원을 찾아 줘요. "괜찮아"면 안내를 계속해요. |
| 하차 | 하차 확인 | 목적지 도착 후 기어를 P로 바꾸면 "반려견과 함께 내리셨나요?"를 물어 차량에 반려견이 남겨지는 일을 막아요. |

### 운전 중 조작을 줄이는 설계
- **음성 중심**: 장소 검색과 팝업 대답("응/괜찮아")을 음성으로 처리
- **내비게이션 옆 분할 화면**: 가로(1700×1184)와 분할 세로(840×1184)를 모두 지원하는 반응형 UI
- **정차 중에만 조작**: 프로필 수정·맞춤 온도 조절은 기어 P에서만 활성화
- **최소한의 정보**: 검색 결과는 3곳, 카드의 조건 칩은 2개까지만 표시

## Pleos SDK 활용

| SDK | 사용처 | 상태 |
|---|---|---|
| SpeechToText | 장소 검색 문장, 팝업 대답(응/아니/괜찮아) 인식 | 1차 구현 |
| TextToSpeech | 탑승 질문, 안내 시작, 휴식 권고, 하차 확인 음성 | 1차 구현 |
| NaviHelper | 선택한 장소로 길안내(`requestRoute`), 경로 상태·목적지 도착 감지 | 1차 구현 |
| Vehicle (HVAC) | 실내 온도 조회, 맞춤 온도로 공조 설정 | 2차(PT) 예정 |
| 차량 기어·주행 시간 | 정차 중 조작 제한, 연속 주행 시간 계산 | 2차(PT) 예정 — 1차는 시뮬레이션 |

## 실행 방법

1. Android Studio에서 프로젝트를 열고 Gradle Sync
2. Pleos Connect 에뮬레이터(API 34) 실행
3. 에뮬레이터 마이크 켜기: Extended controls → Microphone → **Virtual microphone uses host audio input**
   (또는 `adb emu avd hostmicon`, 콜드 부트할 때마다 필요)
4. (선택) Extended controls → Location 에서 위치 지정 (예: 서울 시청 37.5663, 126.9779)
5. ▶ Run → 위치 권한 허용

| 🎬 녹화용으로 숨기기 | 패널 숨김 (같은 자리를 누르면 다시 표시) |

## 서버 API (요약)

| 메서드 | 경로 | 설명 |
|---|---|---|
| GET | `/api/v1/places/search` | 음성 문장·위치·반경으로 반려견 동반 장소 검색 (최대 3곳, 페이지) |
| GET | `/api/v1/places/{placeId}` | 장소 상세 (영업 시간, 주차, 동반 크기·조건 등) |
| POST | `/api/v1/users` | 차량 앱 사용자 토큰 발급 |
| POST/GET | `/api/v1/pets/me/qr-code` | 프로필 입력용 QR 발급·상태 조회 |
| GET | `/api/v1/pets/me` | 반려견 프로필·맞춤 온도 조회 |

장소 데이터: 한국관광공사 반려동물 동반여행 데이터 + 팀 자체 수집 데이터
